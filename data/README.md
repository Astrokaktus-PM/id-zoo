# Справочники веб-макета

- `cities.json` — 1117 городов России с координатами и населением. Источник: HFLabs, «Города России»,
  https://github.com/hflabs/city (коммит `ae661bf`, 2021-10-11). Лицензия исходных данных — CC BY-SA 4.0
  (https://creativecommons.org/licenses/by-sa/4.0/); этот производный файл распространяется на тех же условиях.
  Изменения: оставлены название, регион, координаты (4 знака), население; для одноимённых городов к названию
  добавлен регион; отсортировано по населению.
- `breeds-dog.json` — 379 пород собак. Источник: РКФ, «Номенклатура пород, признанных FCI и РКФ, с классификацией
  по размерам» (Приложение №1 к Положению РКФ о племенной работе, rkf.org.ru, файл 2022/06). Основные породы без
  разновидностей, названия приведены к обычному регистру. Пород кошек в справочнике нет: проверенного источника
  на русском не подобрано; для кошек — «Беспородная», «Метис» и свободный ввод.

Порода в модели благополучия ни на что не влияет — это удобство ввода.
